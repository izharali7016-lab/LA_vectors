Vector fundamentals

A vector is an arrow with a length and a direction. Its components tell you how far it goes along each axis. Drag an arrowhead, or type values.

Common mistakes

Confusing a vector with a point: a vector can be drawn from anywhere, only its components matter. The angle comes from atan2(y, x), not atan(y/x), which loses the quadrant.
